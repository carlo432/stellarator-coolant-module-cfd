# v5 Isothermal RANS Water Re10000 Clean

This is the first higher-Reynolds-number water debug case.

## Physics

- water debug fluid
- Re about 10,000
- inlet velocity: 0.3348 m/s
- isothermal
- steady RANS
- k-omega SST

## Purpose

Check whether the baseline geometry and solver setup remain stable at the first serious RANS Reynolds number before adding heat transfer.
